# Android standalone reader

Reading time pauses when Android puts the app to sleep or it becomes inactive. It resumes when the app is active and the reading page is visible. A book that finishes opening in the background does not start counting time until the app becomes active.

Debug builds appear as Kobalt on the home screen. They use a separate app ID from releases and add `-debug` to the displayed version. Both apps can be installed together. Each keeps its own books, settings and reading progress.

Android uses the shared reader UI and unprotected EPUB pipeline without Nickel. The app starts in the [library](library.md#library). On first use, Open a single book opens the document picker; Choose folder opens the system folder picker and scans for books. Books opened individually or through another app's Open with menu join the library and open immediately. Imports are copied into app-private storage, with a 128 MiB limit. Reading position, bookmarks and settings stay on the device. While opening, Kobalt shows the same loading layout, logo, progress bar and delayed hint as Kobo. System Back cancels opening or returns from the reader to the library. At the root library, system Back leaves the app. By default, Volume Down and Page Down advance on the initial key press; Volume Up and Page Up go back. Settings > Controls > Hardware buttons maps each available volume button to Previous page, Next page or Do nothing while reading. Page Up and Page Down keep their directions. Devices without volume keys hide Hardware buttons. These keys follow the reading order in both left-to-right and right-to-left books; touch swipes follow the page direction. Holding or releasing a key does not request another turn. Device button remapping can affect when Android delivers these events. Protected or invalid EPUBs show an error over the library; Android has no built-in Kobo reader to hand them to. See [Android limitations and setup](../building.md#android).

The Android launcher icon is an outlined open book with Kobalt's serif K and a bookmark. The artwork fills more of the icon while leaving space for the launcher’s adaptive mask.

Android follows the device’s rotation setting on the start screen, in the library and on the reading page. Its Layout menu omits Kobo’s manual rotation controls. Android shows system bars on the start screen and in the library, and hides them while reading. The Library, the surrounding app surface and system-bar icons use the saved light or dark theme, including after returning from a book. The book-opening screen stays visible until the system bars finish hiding and the first page is ready at the final reading size, with its discovered images loaded. On Android, the Library stays inside the system safe area, below the status bar and above the navigation bar. While a book is open, the system bars are hidden and a camera cutout at the top or bottom becomes the reader's safe area: the page paper fills the band, the text and the menu bars start inside it, and footer text keeps clear of the rounded screen corners that Android 12 and later report. A cutout at the side stays outside the Library and reader as equal margins on both sides. Their content stays centred. The bands follow rotation and inset changes. On a bookmarked reading page, the ribbon continues through the top camera band to the screen edge. The text and controls keep their safe-area positions.

## Resource folders

In Library, open More > Resource folders. Choose a separate folder for Dictionaries, Fonts and Custom icons with Android's system folder picker. These folders can be on internal storage or an SD card. For example, create `kobalt/dictionaries`, `kobalt/fonts` and `kobalt/custom-pins` on the card, then select each folder. The folder names are suggestions; Kobalt uses the folders you choose. Android can prevent selecting a storage root or a protected folder, so select the subfolder itself.

Tap a row to change its folder. The X beside a selected folder clears that choice without deleting the source files. Cancelling the system picker keeps the previous choice. Folder access survives app and device restarts unless the provider or Android revokes it. No broad storage permission is requested.

Close and reopen a book to load changes. Kobalt refreshes the selected folders on the opening worker and keeps private working copies because fonts and dictionaries need seekable files. It compares names, sizes and modification dates to reuse unchanged copies. Providers without reliable dates are read again. Removed files leave the working copy after a successful refresh. A folder that cannot be read keeps its last successful copy and reports the error. Clearing a choice removes that working copy at the next opening. Original files are never changed.

Fonts use `.ttf` or `.otf` files, directly in the selected folder or up to two folder levels below it. Custom icons use the [SVG format and limits](annotations.md#bookmarks) and must be directly in their selected folder. Dictionaries use the existing StarDict reader: unpack matching `.ifo`, `.idx` and `.dict.dz` files, with optional `.syn`, `LICENSE` and `ATTRIBUTION` files, in the selected folder or up to two levels below it. The supported metadata is StarDict 2.4.2 with `sametypesequence=h`. Keep each dictionary's matching basenames. Invalid dictionaries are omitted. Selected-folder dictionaries appear in the lookup selector alongside downloaded dictionaries; they are not deleted by the downloaded-dictionary manager.

Discovery checks at most 256 entries for icons and 2,048 entries for fonts or dictionaries. Each font is limited to 100 MiB and each dictionary file to 512 MiB. A working copy is limited to 1 GiB. If a folder exceeds these limits or copying fails, Kobalt retains its previous successful copy. Oversized SVG files are retained as rejected names for the custom-icon warning. The first refresh needs enough free app storage for the selected files; a changed snapshot temporarily needs space for both copies.
