# Reader chrome checks

Label `chrome`. Build `mac-tests`, then run `ctest --preset mac -L chrome` from `platforms/desktop/`. `ctest --preset mac -N -L chrome` lists its tests.

These checks cover the header and footer, the reading strips, the status strip, battery and reading-time fields, the clock and its timers, time-remaining text, the 150% interface text layouts and the return header. `model.header-footer` holds the layout model. The `lifecycle` checks drive the production reader with a test clock, and the `desktop` and `ui` checks measure the strips and the return header in pixels.

`lifecycle.turnSkipsHiddenControls` counts host battery reads during a page turn with the menu hidden and a battery field assigned to a disabled header. The menu and the header preview must show the current charge when opened. `desktop.batteryPercentageOnly` checks the chooser's sample before assigning a battery field and the reading strip's value after reopening the book. `desktop.zenBattery` checks that the Zen menu hides the battery at 21% and shows it at 20%. `lifecycle.sleepScreenUpdatesWhilePluggedIn` changes the host charge state before sleep without sending a notification. The first sleep frame must already show that state.

The lifecycle clock checks count calls to the host clock formatter. A page turn with a disabled time field and the menu closed makes no call. The reading strips, menu, slot preview and field chooser reuse the formatted time within a minute. A changed minute, date or UTC offset starts a new sample. Waking or opening a new reader in the same minute picks up the host's current time format.

Set `KOBALT_READING_TIME_CAPTURE_DIR` to an absolute directory to capture the status strip in `lifecycle.readingTimeStatus`. Set `KOBALT_CAPTURE_HEADER_FOOTER` to a workspace directory to save the strip images of `ui.chapterPageSurvivesLongTitles`.

`desktop.headerFooterBookStatus` opens a generated book with 300 songs in one spine item in Hybrid with Book status in the header, turns pages and records every value the field shows. It checks that the layout shows a percentage on the way and ends with full and its time, and that its 5-second timer runs only while the field is in a strip. With `KOBALT_KOBO_EMULATION=20` the recorded values step through the percentages. `model.header-footer` checks its texts for the turn time, progress, failure and both time formats. `desktop.headerFooterChapterMode` opens the book fixture in chapter mode with the book page, the chapter page, the page turn time and the chapter load time in the strips. It waits for the asynchronous page estimate after the first frame, then checks that both page fields show a page and a total, and that forward turns add one page, also across a chapter start. It checks that both time fields show milliseconds and that the chapter title does not contain the load time. It runs in debug mode, so the field list offers both times; `desktop.settingsDebugMode` checks that the list leaves them out otherwise. Set `KOBALT_CHAPTER_PAGE_CAPTURES` to an absolute directory to save the six-inch reader at a chapter start, in the middle of the chapter and at the start of the next chapter, with normal and 150% interface text.

`desktop.headerFooterCountsWithoutTurn` opens a generated book of 300 spine items in Hybrid, closes it before the whole book is laid out and opens it again. Without a page turn, the book page field must go from Calculating… to the estimate. After turns start the build, it must show the exact count without another turn, while the reader still shows the chapter. Fewer spine items than a whole-book record holds give every item its exact pages.

`lifecycle.clockRestsWithoutConsumers` checks that the minute clock rests while no strip field, menu or host needs it, and that the menu starts it. With `lifecycle.clockAsksPaceForTimeLeft` it also checks that the reading pace is asked only for a visible consumer. `lifecycle.minuteClock` and `lifecycle.idleTimers` check timers on the main thread only. The minute clock test advances wall time through standby and checks that resuming twice runs the missed tick once. Worker-thread timers and Kobo-only timers are out of scope. `platform.nickel-reading-pace-cache` checks the pace cache, but the reader coordinator's 65-second fallback timer has no automated check.

`desktop.percentageFormat` checks the Settings choice, draft and save behavior, reopening Settings, header/footer previews and unchanged page counts and progress. The model checks cover invalid saved values, whole-percent defaults, fractional progress, rounding, unknown lengths, large books and the last page. The gallery includes the Settings row, choice dialog, reading page and header/footer preview.

These headless checks do not establish physical-device refresh or behavior.
