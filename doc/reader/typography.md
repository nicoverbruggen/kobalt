# Text and typography

New books inherit the text style of the last book read. Settings > Defaults can disable text inheritance. Margins apply globally regardless of that choice. Without an inherited style, new books use the default reading font, initially Libron, at 11 pt, 150% line spacing, left alignment, 48 side margin units, 24 top/bottom margin units and hyphenation off. Left alignment and justification preserve publisher-centered text, headings and illustrations. Auto keeps all publisher alignment and is the last option in the alignment control. Text size ranges from 6 to 48 pt. Dragging snaps to evenly spaced marks at 6, 7, 8, 9, 10, 11, 12, 14, 16, 18, 20, 24, 28, 32, 40 and 48 pt. The plus and minus buttons change size by half a point when the current size is below 32 pt, and by one point at 32 pt or above. One-point steps preserve half-point offsets in existing books. Margins are set in units of a 300 ppi pixel from 0 to 120, so both look the same on every screen. Kobalt saves them globally in 300 ppi units. Text and Layout open over the current page without waiting for a preview. After the panel paints, Kobalt prepares the current-section preview in the background. This does not replace or refresh the reading page. A setting change uses that preview and applies when the panel closes. The controls stay enabled while the preview opens or renders. A drag applies its final value on release, and a change made before the preview opens waits for it. Settings opens at once while a draft renders; closing it applies the newest draft and waits only for a preview that has not opened yet. The font button's sample follows the displayed page, so a thickness change updates the book and the sample in the same screen update. Switching panels without an edit does not wait for preview work. The font picker loads only the families on its visible page. Outline thickness redraws glyphs without recalculating layout; variable font weight can change layout. Opening Settings closes the current menu and its dropdowns. A pending Text or Layout draft stays available and applies when Settings closes. Font, size, extra weight, spacing, alignment and hyphenation are saved per book. Margins apply to every book. Line spacing ranges from 100% to 300% of the font size. Dragging snaps to evenly spaced marks at 100%, 110%, 120%, 130%, 140%, 150%, 175%, 200%, 250% and 300%. The plus and minus buttons change it by one percentage point. Older saved spacing is converted once to preserve its approximate appearance: 122% becomes 150%, other values are squared and divided by 100, rounded to a whole percent and capped at 300%. For a selected variable font with a weight axis, Variable weight selects its designed weight within the font's supported range and reflows the page. Thickness adjusts outlines for every font without changing pagination. It ranges from 0 to +12, with a slider mark and a plus/minus adjustment at every integer. Variable fonts show an additional Variable weight slider with marks at the supported endpoints and common weights. Optical size has nonlinear marks within the font's supported range when that axis is available. The two settings are saved independently and can be used together. Variable weight starts at 450, clamped to the font's supported range. Saved book weights take precedence.

Appearance and viewport changes keep the current page visible for the first second. During rotation, the current page continues painting at the new geometry until reflow finishes, so an empty backing store cannot leave the screen black. After one second, a modal and progress bar appear together over the same patterned backdrop as other blocking dialogs. Its single message identifies appearance changes, enabling or disabling Bold Reading, or updating page layout after rotation or resizing. The bar advances across style recalculation and pagination without resetting between phases. Progress updates are limited to one per 200 ms, with phase boundaries and completion reported immediately. The modal closes when the latest request finishes, fails or is cancelled. Ordinary page turns do not show it.

Bold Reading is an optional checkbox in Settings > Display. It emphasizes the first half of each word's letters with the selected family's bold face, with the engine's usual fallback when a bold face is missing. Combining marks stay with their letters. Soft hyphens do not start a new prefix. A word split across inline elements receives emphasis only in its first text fragment. Existing bold text, code, mathematics, ruby, vertical text and scripts that need contextual joining or word segmentation stay unchanged. Prefix emphasis applies to Latin, Greek, Cyrillic and Hebrew, including extended Latin and Cyrillic letters and fullwidth Latin text. The setting is off by default and applies to every book. Changing the checkbox saves and applies it immediately while Settings stays open. A failed save restores the checkbox and keeps the previous reading mode. Upgrades keep the saved Bionic Reading setting unless a Bold Reading setting already exists. Thickness and Variable weight are disabled while Bold Reading is enabled; their stored values return when it is off. Toggling the checkbox keeps the reading position and repaginates the book. Search, selections and links use the original text positions.

Exit waits for a pending appearance preview and its application before saving the reading position. If the preview cannot open, or the engine rejects the change, Exit can still close the book with the last usable appearance. A settings-file write failure keeps the draft open for a retry. Any failed reader settings save shows a Disk write error dialog. Changes that could not be saved stay unapplied.

A full-size SVG that is the only content in a chapter fills the reading area and follows its SVG aspect-ratio and alignment settings. A full-height table that is the only content in a chapter also uses the reading area, including vertically centred verse. Images and tables alongside other content keep their ordinary layout. Tables at chapter starts retain their chapter break with either spacing preference.

## Fonts

The font picker shows a compact grid above the navigation tabs, with the book still visible above it. The first choices are Publisher Fonts, Libron and a Set default font help button. Small uppercase captions show the number of usable embedded font families and the default font. When no embedded fonts are available, Publisher Fonts shows its selected serif fallback in its caption. A cell too short for the name and its whole caption drops the first caption lines, so the name keeps a full line. A checkmark marks the selected reading font. Phone pages hold six choices: two columns in portrait and three in landscape. Phones omit the Set default font help tile; Settings > Defaults and holding a font remain available. E-reader pages hold twelve choices in three columns, or six columns on a short, wide screen. Each name uses its own face. Font names wrap at word boundaries onto two lines when needed. Names that still exceed the available space use an ellipsis. Font-name previews and the selected-font control follow the current reading weight or Bold Reading mode. Captions and the Aa help icon keep their normal appearance. Use the arrows to browse, select a font to preview it in the book, and choose the X to return to the Text panel. The first page contains only recommended fonts, including Ancizar Serif and Literata. Later pages have separate sections for Nickel's built-in fonts, sideloaded fonts from `/mnt/onboard/fonts`, and supplemental fonts for the book's language. The built-in section contains TrueType and OpenType fonts installed with the firmware, including Kobo's compressed `QTD` fonts. Encrypted `QTE` fonts are unavailable in the public reader. Kobalt keeps decoded copies in temporary storage for the renderer and font-name previews. It does not change the firmware files or include Kobo fonts in its packages. Unreadable fonts are skipped. Firmware 4 uses Kobalt's private font renderer for font-name previews to avoid loading reading fonts through Qt 5.2. Bundled and sideloaded fonts remain available. Display names omit the `NV ` prefix; saved selections keep the original family name. Publisher Fonts keeps the book's own font declarations. Sideloaded fonts can sit directly in `/mnt/onboard/fonts` or in folders up to two levels below it, such as `fonts/Family/static/`. Deeper folders, hidden files and folders, and Kobo's wrapped fonts, such as those in `fonts/kobo/`, are skipped.

Font pickers hide a KF variant when its matching NV family is available. They also recognize the unprefixed collection families Libron, Sourcerer, Cartisse and Readerly. A KF-only family remains available. The current choice remains visible, including a KF choice saved by an earlier build. Opening a picker does not replace saved font choices or change reading data. The reading picker also retains the default font.

Long press a font, including Publisher Fonts, to make it the default for new books, then confirm the change. On desktop, right-click or press Shift+F10 for the same dialog. The chosen font stays in its normal grid position, shows Default font below its name and becomes the initial font choice for new books when text inheritance is off or no previous style is available. Existing books keep their selected font. Publisher Fonts keeps the book’s font declarations and automatic fallbacks. Long press Libron to restore the built-in default override. The Aa help button beside Libron uses the current default override inside a circle and always shows instructions when tapped. It does not change the default or the selected reading font.

Fonts with an optical-size axis show an Optical size slider below Text size. The slider uses whole-point steps and does not change the text size. Fonts use their declared optical-size default, rounded to a whole point. The manual value is saved with the book and restored after reopening. Fonts without this axis hide the row.

## Columns

In two-column mode, a chapter's total includes the screen containing its final column. If the next chapter starts in the second column, that screen counts toward both chapters. A chapter occupying two full columns and one partial column therefore starts at 1 / 2. The mixed screen can show 1 / 7 for the next chapter.

Settings > Display has a Columns section below Appearance. Use two columns in landscape controls the reading layout. It applies to all books and starts disabled. When enabled, landscape uses two columns and portrait uses one. Column spacing stays visible below that setting and is disabled while it is off. It ranges from 1.0× to 3.0× the current text size in steps of 0.5×. The default is 1.5×, marked as default in the picker. An existing saved spacing remains selected. Increasing the text size increases the gap without changing the outer margins. Layout keeps the horizontal and vertical margin controls and rotation. Text flows down each column before continuing in the next, and a turn advances a complete screen. Columns render at their own width without stretching text. Side margins apply only to the outside of the screen. Top and bottom margins apply to every column. Search, links, annotations, navigation previews and saved positions use the complete screen. Column settings are global and do not follow per-book text inheritance.

## Styling

Settings > Styling selects global fallbacks for `serif`, `sans-serif` and `monospace`. The bundled defaults are Libron, Legible Next and IBM Plex Mono. Mini packages use IBM Plex Sans when Legible Next is absent. With Publisher Fonts selected, the serif and sans-serif choices resolve generic families and books without embedded fonts. Named publisher fonts and embedded fonts keep precedence. Without a custom choice, books with embedded fonts keep the existing publisher behavior, including previews of chapters without embedded fonts. A selected reading font overrides serif, sans-serif and named publisher families. Code uses the selected monospace fallback, including under an explicit reading font. MathML keeps Noto Sans Math. Missing fallback fonts return to the bundled default when a book opens.

Settings > Styling groups its choices under Words and letters, Paragraphs, Page breaks, Book normalization and Book content. Words and letters contains Word spacing and Justification tracking. Page breaks contains Widows and orphans, Page spacing and Pages to adjust. Each row has an icon, describes its effect and names its current choice. Tap a row to open its sheet. The sheet is wider than other settings popups, with the usual clearance at the screen edges. It shows a preview, a segmented control or slider, a description of the selected option and a note. The description keeps the height of the longest option's text, so the controls below it stay in place. The sheet stays open while you choose, so you can compare the options. Close it with its close button or by tapping outside. Blocking settings popups fade the background and cover it with diagonal lines. The card stays clear. Dark mode uses light lines over a dark background. The previews are pages of a short bundled sample, laid out by CREngine on the engine worker. Word and letter samples use the book's current typography, including its reading font, size, spacing, margins and theme, and the Styling choices made so far. Page-break samples use a fixed page instead: a six-inch page at the screen's density, Libron at the default size, 140% line spacing and the default margins, justified. Only the theme and the page-break choices come from your settings, so the sample reliably shows single lines at page edges and the gaps they leave. Widows and orphans, Page spacing and Pages to adjust draw stored text positions with Libron on the interface thread. These previews are ready when the sheet opens, without waiting for the reading engine. Their fixed illustrations preserve the original text, line breaks and interactions between page-break choices. Word spacing, Paragraph adjustments and Justification tracking still render with the engine. Closing Settings stops unfinished engine samples so they do not delay the book. Word and letter settings show the whole lines at the top of the first sample page at full resolution, with paper above and below. The preview scales them down only when a line is wider than the sheet. Page-break settings show two pages, scaled to fit. Page spacing outlines the reading area on both pages with a dashed line. Below them, a larger view of the bottom of the changed page hatches the height each option leaves without text: below the last line with Normal, between lines with Expand, and above and below the text with Center. The illustrations retain the original sample’s line positions and spare-space measurements. Each combination shows the original spread where the options differ. When the options look the same, the sheet says so. Word spacing defaults to Normal (100% of the font’s space width). Narrow uses 80% and Wide uses 120%. It changes the normal width of spaces and can change line breaks and page count. Justification can still stretch spaces to fill a line, so two options can look the same on justified text. Automatic space shrinking remains disabled. Justification tracking defaults to Normal, which keeps normal letter spacing. Its sample is always justified. The sheet's note shows the current alignment and explains that the preference affects all books. Left, centered and right alignment explain that tracking has no effect now; Publisher explains that the book controls alignment. Subtle and More allow adaptive letter spacing of up to 5% and 15% of the font size on loose justified lines. Lines that need no more than the subtle amount look the same with both. The engine adds spacing between eligible glyph clusters without stretching glyphs or changing line breaks. Other alignment modes keep their spacing. Cursive words and CJK glyphs are excluded. Widows and orphans defaults to Publisher, which keeps the book's rules and otherwise allows single paragraph lines at page boundaries. Avoid both overrides publisher rules to keep at least two paragraph lines together at each boundary. Allow both overrides publisher avoidance. Avoidance can leave blank space at the bottom of a page and can be relaxed when content cannot fit. These choices apply when Settings closes and persist across books. Custom user CSS can override them with `!important`.

The Page spacing sheet in Settings > Styling > Page breaks selects Normal, Center nearly full pages or Expand line spacing. Normal is the default and keeps the usual line spacing and top alignment. Center nearly full pages is the recommended adjustment, so it comes before Expand. When the full names do not fit their segments, as on a phone, the segments read Normal, Center and Expand, and Pages to adjust reads All pages and Widows only; the text below the choices names the full option. It moves the prose as one block when its line boxes occupy at least 90% of the reading height. It does not change line spacing. Expand line spacing spreads spare height between lines without changing page breaks or the first line's position. The Pages to adjust row below it opens its own sheet, which selects All suitable pages or Only widow/orphan gaps with the same preview. It is unavailable while page spacing is Normal. The latter applies only when paragraph protection moves text that would otherwise fit on the page. It has no effect when those rules are disabled or do not affect the page break. Both choices apply to all books when Settings closes. Each column adjusts independently. Expansion keeps chapter endings unchanged and limits added leading to 12.5%. Centering can adjust a nearly full ending page. Recognized decorative images, headings and figure captions keep their internal spacing while surrounding prose can adjust. Expand adds leading only between consecutive prose lines, with at least six prose lines and the existing spare-height limits. Decorations and captions do not count toward that minimum. A CSS opening initial keeps the preceding content and its paragraph fixed; Expand and Center can adjust the prose below that prefix. Center requires that prose to fill at least 90% of the remaining height. Unknown media, tables, lists, preformatted or vertical text, unrelated floats, visible borders, backgrounds and footnotes keep their protection. Sparse pages stay unchanged. Text selection, links and highlights follow the displayed text.

Styling prepares each preview when its sheet opens. Opening the Styling tab does not prepare samples. Prepared choices can be reused until settings changes invalidate them or Settings closes.

Styling previews use prose from Alice’s Adventures in Wonderland, chapter I. `assets/samples/words-and-letters.html` supplies Word spacing and Justification tracking. `assets/samples/layout.html` supplies Paragraph adjustments. Keep valid XHTML, with paragraphs and headings directly inside `<body>`. Inline emphasis is supported. The source credit is in each file. The page-break illustrations use `src/app/reader/settings/style_illustration_layouts.h`, which stores typed text and position tables from the original layout sample at 1072 × 1448 pixels with Libron at 46 pixels and 140% line spacing. Words and lines are shared by pages, and pages are shared by setting combinations. Changing the XHTML does not change these fixed illustrations. Each word records a shared text index, horizontal position and italic flag. Each placed line records its shared words and baseline. Font size is stored once. The interface draws the text at the preview resolution and uses the stored line measurements for the enlarged bottom edge. Compare both themes and device sizes with the original captures when editing this data.

Settings > Styling > Paragraphs contains Paragraph adjustments. Its modal reuses three consecutive paragraphs from the Widows and orphans sample, with wider paper margins, above two sliders. The same diagonal hatching as Page spacing marks the extra gap between paragraphs, excluding normal line leading. Continuation lines show the effect of indentation. Each slider starts at Publisher, which keeps that part of the book's formatting. Spacing sets a fixed gap from 0% to 200% of the text size. First-line indent sets 0% to 300%. Both sliders snap to Publisher and 25% steps from 0% through 200%. First-line indent also snaps to 300%. Intermediate stops have no extra tick or label. The visible markers keep their original positions. With 12 pt text, a 100% indent is 12 pt. The plus and minus buttons adjust each value by one percent of the text size. Releasing a slider renders the sample with both choices. Custom spacing replaces vertical margins and padding on ordinary text paragraphs; custom indentation replaces their first-line indent. Headings, centered text, illustrations, quotations, lists, tables, notes, recognized verse and decorated or preformatted blocks keep their formatting. Unrecognized publisher markup can still need custom CSS. Both choices apply to every book when Settings closes. Styling preview modals stay centered and are no wider than a seven-inch portrait screen, scaled for display density, including on larger landscape screens.

## Text rendering

Zero-width spaces and word joiners stay invisible, including when a font supplies a visible control glyph. Missing thin and hair spaces stay blank. HarfBuzz supplies their spacing when the last fallback font lacks the glyph. The source text keeps its original characters and line-breaking rules.

On Kobo Qt5 and Qt6, plaintext raster images stream from the EPUB ZIP in blocks of at most 64 KiB. Image dimension requests read only the header and send no image body.

CREngine renders supported MathML directly, including stacked fractions. Noto Sans Math supplies the generic `math` family and default MathML font. When Publisher Fonts is selected, explicit publisher font names remain in effect. Choosing a reading font keeps MathML on Noto Sans Math so operators and fractions use its mathematical metrics. PNG, JPEG, GIF and SVG illustrations render in the book. GIF illustrations are static. Images keep their publisher spacing and CSS dimensions without automatic enlargement. When an HTML `img` has two positive dimensions, `max-width` and `max-height` shrink both dimensions together to keep the specified proportions. This applies to attribute and CSS dimensions, including SVG files loaded through `img`. This reading compatibility rule differs from browsers that clamp the two specified dimensions independently. Images that fit keep their specified dimensions, even when their proportions differ from the image file. Explicit zero sizes, automatic dimensions and CSS minimum constraints keep their existing behavior. Inline SVG keeps its own viewport and `preserveAspectRatio` rules. With Reduce publisher spacing enabled, a one-pixel layout boundary retains positive top margins on leading illustrations. Structural CSS selectors such as `:only-of-type` and `:nth-of-type` preserve publisher image spacing and centered text when opening a book or previewing appearance changes. CSS pixel and physical units use the reading screen's density. Inherited paragraph indentation keeps its direction at every text size. Explicit hanging indents remain supported. Font-relative equations scale with the reading text. In dark mode, images marked as equations with `data-tex` or `role="math"` invert neutral ink while preserving coloured parts and transparency. Ordinary illustrations keep their colours.

Dark mode inverts gray and faintly tinted text on gray backgrounds. Text on colored backgrounds keeps its publisher colors and contrast. More saturated text and ordinary illustrations keep their colors.

Code (`pre`, `code`, `kbd`, `samp` and `tt`) uses IBM Plex Mono, also when you choose a reading font. If the reading font has no glyph for a character, Noto Serif supplies it, then Noto Naskh Arabic and Noto Serif fonts for Hebrew, Armenian, Georgian, Devanagari, Bengali, Tamil and Thai, followed by Noto Sans Math and Noto Serif CJK. Script fonts precede Math so letter shaping uses the text font. Math precedes CJK so shared mathematical symbols use the math font. These fonts cover Greek, Cyrillic, phonetic symbols, mathematics, Chinese, Japanese, Korean, Arabic, Hebrew, Armenian, Georgian, Hindi, Bengali, Tamil and Thai. Non-CJK text uses bundled bold faces where available. Noto Serif and Noto Serif Tamil also include italic and bold italic faces. CJK and math keep their regular faces. The picker offers the matching supplemental family for the document language. A supplemental font that is selected or made the default remains available when another language is opened.

Noto Serif CJK uses the book's language and inline `lang` attributes to select regional glyph forms. Text without a recognized CJK language uses Japanese forms. The bundled Regular collection includes Japanese, Korean, Simplified Chinese, Traditional Chinese and Hong Kong Chinese faces. Font coverage does not enable vertical layout.

Chapter lists, chapter headers and single-line interface controls use the bundled Noto fallback fonts for characters missing from the interface font. Kobalt shapes and draws this fallback text with its own font libraries. It loads fallback font bytes when text first needs them and shares the CJK collection between its regional faces. Coverage does not depend on the selected reading font or opening the font picker. CFF and collection fonts also use this path for font-picker samples and search excerpts, instead of the firmware font driver. Firmware 4 search excerpts use this path for every reading font. Matches stay bold and underlined, and excerpts end between complete lines.

Arabic and Hebrew text uses FriBidi for right-to-left ordering and HarfBuzz for letter shaping and mark placement. Paragraphs can mix right-to-left text with Latin words and numbers. Without a publisher or reader alignment override, paragraphs align to the start of their text direction. The bundled Arabic and Hebrew fonts also supply missing glyphs in chapter titles and other interface text. Text direction and EPUB page-turn direction are separate; the spine's page progression still controls taps and swipes.

Thai word selection follows Qt’s Unicode boundaries. It can select a letter cluster rather than a complete dictionary word.

The book's `dc:language` sets the text language, and `lang` attributes set it for parts of the text. The language selects the hyphenation dictionary and the line-breaking rules. CREngine uses libunibreak for Unicode line breaking and its supported CSS `line-break` and `word-break` rules. Kobalt has dictionaries for English (US and UK), German, Dutch, French, Spanish, Italian, Portuguese (Portugal and Brazil), Estonian, Finnish, Georgian, Hungarian, Latvian, Lithuanian, Polish, Russian, Slovak, Slovenian and Ukrainian. Other languages recognized by CREngine use algorithmic hyphenation when their dictionary is not bundled. Books without a language declaration default to US English patterns. An unrecognized language tag also selects US English patterns. The hyphenation setting still decides whether text is hyphenated.

Dark mode automatically inverts grayscale illustrations with mostly white backgrounds and white borders. Colored images remain unchanged. A grayscale photograph with a white background can also qualify. This applies to images inside books, including SVGs. Library covers remain unchanged.

Kobalt always smooths scaled images and draws its own text slightly heavier: menus, panels, Settings, Stats and the header and footer. It does not change the book text, which has its own weight setting. The interface adds 3/256 em to each stroke with the same FreeType emboldening as three steps of the reading weight, and keeps every letter's advance, so no text moves or wraps differently. Displayed app text uses Kobalt’s GUI-thread FreeType, HarfBuzz and FriBidi renderer, including Latin text, dictionary definitions, footnotes, previews and license pages. It owns font metrics, wrapping and pagination. Qt parses rich-text markup without loading external resources. Reading-font bytes remain available even when Qt cannot register a face. Bold and italic are synthesized when the selected face lacks them. The book renderer keeps its separate worker-owned font manager. Editable search and dictionary lookup fields and native operating-system controls retain Qt rendering. Kobalt registers the bundled IBM Plex Sans, IBM Plex Mono and Instrument Serif with Qt unchanged for these controls, so they draw in the regular weight without the added strokes. Optically centered UI labels, including Exit Kobalt, use the same added weight. Font samples use their explicit preview weight. Search excerpts in the book’s font keep their weight.

Text controls save the font, size, weight, optical size, line spacing, alignment and hyphenation per book. Layout controls save margins, header and footer choices, and Kobo orientation globally. These choices apply to existing and new books and persist across launches. An existing global choice takes precedence over an old book-specific choice. Before migration, the last text-style snapshot supplies the current margins. If no global header/footer or orientation choice exists, the first opened book supplies its old choice. Margins are stored in 300 ppi units and converted to the current screen density. The advanced text options in Settings remain global. Android continues to follow system rotation.

Page layout has left/right and top/bottom margin sliders. Each slider changes both margins in its pair together. Both sliders have evenly spaced marks at every 3 margin units, matching their drag and plus/minus increments. Rotation controls ignore input while layout recalculates and keep their current appearance, avoiding an extra refresh for temporary disabled styling. Top and bottom margins add space inside the reading area after the header and footer have reserved their space. The shared margin choice replaces old per-book insets. Page layout also has orientation and the Header and footer row. When the book progress line is shown, the footer text uses the same edge spacing as the header. On Kobo devices with an orientation sensor, the rotation choices are Portrait, Landscape and Both. Portrait is the default. Rotation labels appear beside the icons when all three choices fit at the normal label size. A narrower row shows icons only, preserving their size and accessibility names. Split buttons use white unselected segments, thin borders and black selected segments. Both follows all four sensor orientations. Each lock follows the sensor within its two matching orientations and ignores the other orientations before they can resize or repaginate the book. Flat and undefined readings cancel a pending turn. Opening a book keeps a permitted sensor or screen orientation without turning upright first. Rotation freezes when sleep is requested, before the sleep screen is ready. Pending turns and sensor readings received during sleep are discarded. Sleep keeps the reading orientation when it is on the same axis as the opening orientation. A quarter turn returns to the opening orientation for sleep. Wake restores the saved reading orientation without requiring movement, including after a quarter-turn sleep handoff. A new permitted sensor reading after wake can correct it if the device moved while asleep. The shared sensor has no immediate polling API, and its cached reading can predate sleep. Closing the book returns rotation to Kobo before Home repaints. An active native sensor receives the latest valid awake reading immediately, so Home follows the held orientation without another movement. Without an active native sensor, or when closing asleep, the opening orientation is restored. Enabling Both uses the latest sensor reading received by the reader. Existing portrait or landscape preferences become the matching lock, and saved Auto becomes Both. Devices without a sensor keep the four manual orientation choices.
