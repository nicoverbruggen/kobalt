# Dictionaries

- Hold a word for 500 ms to look it up in an installed dictionary. The definition opens in a sheet across the screen, on the half away from the word. On a screen shorter than 3.4 inches, the sheet grows to up to 62% of the height so a definition has room, but it never covers the word.
- Dictionary lookup accepts individual Han characters in Chinese and Japanese text. It uses Unicode boundaries, not a Japanese morphological dictionary, so it does not infer compound words.

If the page or text layout changes during a hold, Kobalt discards the old lookup target. The long hold does not turn a page or open the reading menu; release and hold the word on the new page. A decoded image that leaves the text layout unchanged preserves the hold and any word selection already in progress. Short taps and swipes keep their normal navigation behavior during page updates. Cancelling the contact prevents later lookup and navigation from it.

## Downloaded dictionaries

Dictionary downloads are disabled on Kobo, and its settings omit the Lookup tab. Kobo lookup uses Nickel's installed dictionaries, including dictionaries in `.kobo/custom-dict`. Standard and custom dictionaries remain separate choices when they share a language suffix. Custom choices keep Nickel's custom label and are saved by file path, so installing or removing the standard dictionary does not change the selected custom dictionary. Lookup uses the installed entry shown in the selector even when Nickel lists an uninstalled standard dictionary with the same language suffix. The Kobo reader does not start the download manager or use dictionaries previously downloaded through Kobalt.

On desktop and Android, open the Lookup tab below Styling in settings to install and remove downloaded dictionaries from one paged list. Dictionaries for the book's language appear first, followed by other languages. Monolingual dictionaries come before translations. Get opens a confirmation with the dictionary name, download size and license. Download starts the transfer; Cancel leaves it uninstalled. A circle in the Stop button shows download progress without changing the row height. Section headers have a gray background, and a divider separates the storage footer. Remove asks for confirmation before deleting an installed dictionary. The footer shows space used and available. The catalogue contains the dictionaries from DanielGregorini's [koreader-dicts](https://github.com/DanielGregorini/koreader-dicts) release v1.2.0. Downloading requires an internet connection.

Downloads run in the background and can be cancelled. Kobalt checks the release's SHA-256 digest before installing. Failed or cancelled installs do not become available for lookup. Licenses and attribution stay with the downloaded files on user storage. Lookup shows one short Dictionary sources line below the definition, with source project names from the archive metadata. The line shortens with an ellipsis if it does not fit.

Tap the pencil beside the lookup word to edit the word or phrase. The sheet moves above the platform keyboard and keeps the definition visible. Edit the query in its existing header, keeping the heading’s typeface and size. A hint below the field explains the action. The check mark or Return updates the lookup in the selected dictionary. Blank queries cannot be submitted. X or Escape cancels editing and keeps the current definition. Editing does not change the selected passage or reading position. Closing the lookup, hiding the reader or selecting another passage discards an unfinished edit.

Tap the magnifying glass beside the pencil in the lookup header to close the definition and search the current book. The search field contains the current lookup word or phrase, including a submitted edit, and results load without opening the keyboard. Cancelled edits keep the previous lookup term. Search in book is hidden while editing. On a window narrower than 3.4 inches, the header's actions use 96-pixel cells instead of 118, and the dictionary's name wraps or shortens before the lookup word does. The action is available even when no definition was found. Selecting a result and Return to original position use the normal book-search controls.

The lookup selector uses the same dictionary names and order. Tap the language icon with the down arrow in the header to open the choices. The button reserves space for the icon and arrow and keeps the same width for every dictionary and language. The list shows the dictionary names and marks the current choice. Its list overlays the definition without changing the definition layout or page count. The definition pager is hidden while the list is open, so only the selector pager is visible. Kobo entries with multiple parts of speech retain separate headings and definition lists. Lookup first uses an installed dictionary for the book's language, with monolingual dictionaries first, then platform dictionaries, then installed dictionaries for other languages. The dictionary chooser uses compact rows in two columns with a vertical divider when the screen is wide enough. Narrow screens keep one column. Language headings span both columns, and the chooser opens at the selected dictionary. Choosing another dictionary applies to that book. The choice is saved with the book and restored on reopening. If the dictionary is unavailable, lookup uses automatic selection. Removing the chosen dictionary restores automatic selection. The StarDict reader uses the supplied inflection index and reads compressed definitions as needed. It prefers exact spelling before a case-insensitive match, so an uppercase acronym does not replace a matching lowercase word. Kobo's built-in dictionaries are kept.
