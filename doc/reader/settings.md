# Settings

On Kobo, System > Advanced ends with Disable standby. It is off by default. Selecting it opens a confirmation that warns about reduced battery life and says it may help with intermittent freezes or missed page turns. Cancel leaves standby enabled. Confirm selects the setting; closing Settings applies and saves it. Clearing the checkbox restores standby without a warning. The setting affects standby while reading, not the sleep screen, closing a book, USB export or shutdown.

On Kobo, the System tab sits above About. Open books automatically in Kobalt uses the same preference as Kobo's Reading settings. A change in either place appears when the other settings page opens. Turning it off keeps the current book open and uses Kobo's reader for future library openings. A failed save keeps the previous selection.

Settings uses section headings within Display, Controls, Defaults, Fonts, Books, Stats, System and the Mac's UI tab. Defaults groups inheritance and Restore appearance defaults under New-book defaults. Fonts contains the three fallback-family choices. Books contains Book content. Dictionaries keeps its existing installed and available groups; About keeps its identity and version block. Settings fills the screen below the top toolbar and covers the reading tab bar while open. Long settings pages use the shared Previous and Next pager below the list, with a page count. The pager has the same width as the list. The tab rail keeps the full panel height and does not shrink when the pager appears. A window narrower than 3.4 inches shows the sections as a list instead, each row with its icon beside its name. Choosing one opens its page at full width, with the section name as the title and a back cell in place of the close cell; back returns to the list. Settings opens on the list; a section that is open when the window turns narrow stays open. A window shorter than 3.4 inches keeps the rail but puts each icon beside its label, so every section fits its height. Complete rows stay together where they fit, and section headings stay with their first option. Content taller than one page continues on the next page. Previous is disabled on the first page and Next on the last page. Short tabs hide the pager. Changing tabs starts at the first page. Resizing keeps the current page when it remains available.

Settings replaces the toolbar action row with a Settings heading and a left-hand close cell. The heading uses the same Kobalt typeface and bottom rule as Chapters. The section tabs stay on the left. Reading actions stay hidden until Settings closes. The close cell applies the draft and returns to the reader. A double tap cannot continue through to Exit Kobalt. Paged lists show an italic More on the next page hint with a down-right arrow in unused space when another page follows and the hint fits. The hint never takes space from rows or appears on the last page.

Unsupported settings remain visible with a description that says they are disabled on this device. Settings rows turn gray while pressed, including toggle rows. Settings choice dialogs dim the rest of the screen until you choose an option, tap outside the card or press Back. Their cards stay opaque.

Pop-ups use the same heading and body text styles. Confirmation buttons use the same height and spacing. Font-section headings have a gray background, and the font panel has the shared thick divider only at its top.

Settings has the following tabs:

- Display: how often the screen refreshes, page animations, then dark mode and Bold Reading. Graphs contains Compact chapter graphs, off by default. Page animations apply only while reading in Kobalt; a handoff to Nickel uses Nickel's own page turns.
- Controls: Navigation contains page navigation and tap zones. Chapter List follows Navigation and contains Collapsible chapters. Links contains Tappable links. Other sections contain the default menu style, Navigate panel button action and frontlight edge swipes. Navigate always includes its slider and book map. Minimal annotation mode is hidden for now; saved preferences remain in effect.
- Defaults: New Book contains Inherit text style from the last book. It is on by default and applies to books without saved text settings. Layout settings apply to all books. Default global font contains Default font, which includes Publisher Fonts and selects the same new-book font as Make default in Text. Existing books keep their selected font. Restore appearance defaults has its own Restore defaults section. Custom presets are planned for a future beta.
- Defaults also contains Fallback fonts, with Serif typeface, Sans-serif typeface and Monospace typeface rows below Default font. Each row opens a dimmed, paged list with compact choice rows in the same order as the font panel: Recommended, Built-in, Sideloaded and Supplemental, with Libron first. Font names preview their own face. Each page loads only its visible families. The popup fits the rows on that page. Typeface selection rows, including Default font and the UI typefaces, show an Aa preview in the selected face before their chevron. Default names the bundled fallback and restores it. Choices apply when Settings closes and persist across books. They resolve generic font families and books without embedded fonts. Named publisher fonts and embedded fonts keep precedence, and a reading font selected in Text keeps its override for non-code text.
- Dictionaries: browse, install and remove downloaded dictionaries. This tab is available on Android and in the desktop app's Fill window mode.
- System: automatic book opening and sleep screen behavior. User Interface follows Sleep and wake and selects independent global fonts for main labels, monospaced captions and section headings, and the reading header and footer. Sans-serif UI typeface controls the main labels. Header & footer UI weight defaults to +2 synthetic thickness steps, with 0, +4, +6 and +8 also available. The choices read Lighter · 0 and Heavier · +2 through +8. Each choice shows SAMPLE TEXT in the selected header and footer font at the current header size. It does not change glyph spacing or book text. Default restores the bundled fonts. These choices do not change the book font. Dictionary UI follows User Interface. Dictionary font selects the typeface for definitions. Default follows the current book’s resolved body font and its normal reading-font fallback. Explicit dictionary font choices remain independent of the book font. Dictionary font size offers Small, Standard, Large and Extra large at 80, 100, 120 and 140 percent. Font names preview their typefaces, and each size shows a short definition in the chosen font. Large and Extra large use at least 110 and 120 percent line height. Choosing a custom dictionary font adds another 20 percent to the automatic line height at every size, including its preview. Existing wider dictionary spacing is preserved. Changes apply across books when Settings closes. The selected word in the dictionary header keeps the book font. Hide labels in tabs sits at the bottom of User Interface. It hides the bottom tab labels and centers their icons while retaining their size and accessible names. Unsupported options remain visible and explain why they are disabled.
- About: version and Qt build, such as "Version 1.0-beta.1 (Qt5)", the short commit of the sources, with `*` when they had uncommitted changes, the description "An alternative EPUB reader with a CREngine renderer and a Qt reading interface, with a focus on speed and an excellent user experience." and acknowledgments.

Confirmation and notice dialogs use the same patterned backdrop as settings choices. Their headings have a divider above the message. Actions share a connected footer, with Cancel on the left and the primary action on the right. If either label does not fit on one line, the actions become full-width stacked rows, with the primary action above Cancel. Labels can wrap with padding. Single-action notices use the full footer width. Bookmark and annotation removal show the page number when available and a shortened excerpt of the saved passage.

## Light

Settings > Display > Show dark mode in Light adds a Dark mode checkbox to the Light panel. The shortcut is off by default. It changes the same dark-mode setting as Settings > Display > Dark mode. Hosts without Light keep the Settings entry. A failed save keeps the previous mode. On short screens, Light omits its swipe hint so the controls fit.

Closing Light through its tab or a tap on the visible page restores the default menu view. Switching to another panel keeps that panel open. Dismissing the reading menu keeps all its panels closed until the menu opens again.

On compatible BOOX Android firmware, the Light tab controls brightness and warmth. Edge gestures use the same setting as other platforms: swipe the left edge for brightness or the right edge for warmth. Cancelled brightness drags restore the original raw level. BOOX automatic light schedules are not exposed. Regional refresh requests use REGAL for light-background text turns, GU for other partial updates and GC for requested cleanup. Physical refresh quality and unchanged header/footer behavior depend on the firmware and need device validation.

Below the brightness and warmth controls, the Light panel offers Automatic brightness on Kobo devices with an ambient light sensor. It uses Nickel's saved sensor setting. Moving the brightness slider or swiping the left edge turns it off and stops any brightness animation already running. Cancelling a brightness gesture restores the original level and automatic-brightness setting. On Kobo devices with adjustable warmth, Follow Kobo warmth schedule uses Nickel's saved automatic warmth setting, including when Kobalt opens for the first time. It follows the bedtime configured in Kobo settings. Manual warmth adjustments turn it off; checking it again resumes the schedule. Opening or closing the reader preserves the setting. Both options use the reader settings' checkbox and label size. They sit together in compact rows, with checkboxes on the left. A thin divider separates these options from the sliders and is hidden when neither option is supported. Nickel keeps its normal sleep and power behavior. The Light panel shows an italic edge-swipe tip with a hand icon above its controls when edge gestures are enabled. The tip sits in a light gray band across the panel, with space before the controls. The short hint fits on one line at six-inch widths. Devices with only brightness control get a left-edge hint. Layout uses Horizontal margins and Vertical margins; slider labels wrap when needed on smaller screens. Both margin controls use the unchanged 0 to 120 range, measured at 300 ppi and scaled for the screen. A drag snaps to stops of 12. The plus and minus buttons change the value in steps of 3. The toolbar and the panel cover the page edges. While Layout is open, a scaled copy of the whole page appears between them, with its header and footer. It sits on the same gray background as the Styling samples. A Preview caption appears beside it when there is room. A dashed line marks the margin that you adjust. A drag only moves the slider. After the release, or after a press of plus or minus, the book is laid out again and the copy updates once. It starts at the first word of the page that you were reading, so the same text stays in place at every margin. Near the end of a chapter it starts earlier, to show a full screen. The page that you read after you close the panel follows real page breaks, so it can start a few lines earlier. The copy does not appear when the space between the toolbar and the panel is too short for a readable page, such as on a phone in landscape. A tap in its space reaches the page and closes the panel.

The Light tab is shown only when the host can control the frontlight. Android has no Light tab.

- A vertical swipe along the left edge changes brightness. On devices with adjustable warmth, a vertical swipe along the right edge changes warmth, and turns off automatic warmth like Nickel's slider does. Each edge zone is 13% of the page width, as in Nickel's reader. Both swipes follow the finger at a constant rate: a third of the page height changes half the light range. Brightness changes round to the nearest whole percentage point, with half steps rounded away from zero in both directions on Qt5 and Qt6. Warmth swipes snap to 10% levels, using the nearest supported hardware step when a level is not available. A popover with a three-pixel border at 300 ppi, scaled to the screen density, on every side shows the percentage and a bulb for brightness or a sun for warmth. The bulb fill follows brightness, with rays added at 30%, 50% and 80%. The warmth rays grow from dots at zero and become thicker at 80%. After release, the final percentage stays visible for at least 1.5 seconds. Its removal requests one full-screen refresh to clear the frame from the page. Cancelling restores the original level and clears the frame with the same refresh. These swipes require host frontlight support; compatible BOOX Android hosts also support them. Settings > Controls > Swipe along edges to adjust frontlight turns both swipes off; they are on by default. Its description names only the swipes that the device supports. Light commands are queued ahead of pending paints and use the latest finger position. The pop-up updates after a 150 ms pause in movement, so it can follow behind the actual light level during a continuous swipe. The separate Show frontlight gesture pop-up checkbox is on by default. Turn it off to keep adjusting brightness and warmth without showing or clearing the pop-up. Successful gestures still save the level, and cancellation still restores the original level and automatic setting. This choice does not disable the gestures or change platform support. The Light panel changes brightness and warmth through Nickel's own settings. Moving the warmth slider turns automatic warmth off, like Nickel's slider does. Follow Kobo warmth schedule turns it back on; bedtime stays in Kobo settings.
