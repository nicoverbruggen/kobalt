# Sleep, USB and power checks

`lifecycle.sleepPillOmitsUnknownProgress` compares the sleeping and charging Pill when progress is unknown and when it is zero.

`lifecycle.sleepGalleryCancelsInterruptedPresses` checks that a touch cancellation or page change during a press does not choose a sleep screen on release. A new tap still chooses the visible design. `lifecycle.sleepCustomEditorShowsTheCover` also checks that a page button leaves the gallery on its current page while the editor covers it.

Asset verification uses the actual USB handoff and completed remount. The lifecycle adapter invalidates assets once after the current request releases storage, even if the reader drain reports completion twice before the USB gadget arrives. A disconnect during asset invalidation restores the profile and cancels the pending Nickel workflow. It requests a recheck only after Nickel's `aboutToUnplug` and `doneProcessing` sequence reopens the volume. An ordinary scan or a stale cancelled completion does not change the verification result. Cancellation after storage release rechecks when the profile becomes available again. `platform.native-lifecycle` checks these callback boundaries. Kobo keeps reading unavailable while the check runs or after it fails.

`lifecycle.readerStandbySetting` checks the default, disabled, invalid and unsupported preference states. It verifies that explicit sleep and a hidden or closed reader are not held awake by the preference. These controlled host checks do not measure hardware standby or battery life.

`lifecycle.sleepOpeningSaveFailure` saves one reading position, moves to a different page, and rejects the SQLite checkpoint for that page. It checks the last durable position during sleep, recovery on wake, a second sleep while Retry is visible, and the different outcomes for required saves and low-battery shutdown. It also checks ordinary reader sleep with the same storage failure. When the opening is parked, the standby callback starts a due SQLite WAL checkpoint and waits for it to finish. At 5% battery with the failure still in place, a parked opening permits standby on every poll and starts no new save. `platform.native-lifecycle` drives sleep, PIN, unlock and cancelled USB through Nickel signals. It checks that only an idle, parked opening save permits standby while the opening is still being cleaned up. `platform.shutdown` checks that power-off, battery-low power-off and reboot wait for the reader's save, also behind a sleep or PIN screen, and that Nickel receives each request once. It runs the ten-second deadline with a save that never ends and with an active writer, and checks that Nickel then continues without waiting for the writer. `lifecycle.usbSavesBeforeReleaseWithinDeadline` checks the USB save, and runs its three-second deadline while Nickel's session never ends.

Label `sleep`. Build `mac-tests`, then run `ctest --preset mac -L sleep` from `platforms/desktop/`. `ctest --preset mac -N -L sleep` lists its tests.

These checks cover sleep screens and snapshots, sleep and wake, session timeouts, USB export, shutdown, power-off screens and the native lifecycle adapter. The `lifecycle` checks drive the production reader with controlled host callbacks and an injected clock. The `platform` checks drive the production Kobo adapters with controlled Nickel signals, substitute native window types and a real profile database.

| Test | Checks |
| --- | --- |
| `platform.native-lifecycle` | The Kobo lifecycle adapter: standby refused while a book opens, the sleep-view handoff and its fallback, PIN rotation, USB entry and power-off |
| `platform.shutdown` | Power-off, battery-low power-off and reboot, and the Nickel Screensaver fixture |
| `platform.kobo-power-screen` | The native power and sleep views and their database reads |
| `platform.sleep-persistence` | The sleep-image writer and native-cover references |
| `platform.usb-removal` | Detecting that Kobalt was removed over USB, once per USB session |
| `desktop.deviceEmulation` | Sleep, wake and power-off through the desktop preview toolbar |

`platform.shutdown` loads `tests/support/screensaver_fixture.cpp` as a shared library with Nickel Screensaver's old call-through behavior and NickelHook descriptor. The fixture does not contain Screensaver's image composition or real Nickel firmware.

`platform.sleep-persistence` does not measure Kobo storage. The opt-in device benchmark is described in [Sleep persistence benchmark](../release-evaluation.md#sleep-persistence-benchmark).

These checks do not exercise physical power loss, firmware behavior, PIN behavior on hardware, sleep-screen refresh quality, actual hook load order, hardware suspend or physical coexistence with Nickel Screensaver. Physical sleep and wake on Kobo and Android need device validation.

The highlight sleep regression holds the engine at save preparation and text collection while the reader sleeps. It requires the accepted highlight to reach storage, the late write to become durable before standby, and subsequent engine work to stay paused until wake. A selection without Save remains unsaved. The engine gate checks overlapping save drains and wake during a drain. Annotation checks cover rejected saves, stale replies, destroyed owners and failed storage writes while sleep is requested.

`model.appearance-settings` checks every gallery choice, legacy backdrop and indicator combinations, changes made by older releases, invalid designs and greeting limits. `lifecycle.sleepGreetingEditor` opens Night with a long press, saves and reopens a greeting, restores the default with an empty field, and cancels an edit through the windowless desktop host. It does not verify the native Kobo keyboard.

`lifecycle.sleepDesignsRepaintOnlyTheirStatus` compares a battery-status repaint with a fresh render for each new design in both themes and orientations. For Night, it also checks that the saved battery area contains the painted sky and that charging renders correctly if the saved area is missing. `lifecycle.sleepSettingsShowWhereToAddPngs` checks gallery paging and the unavailable PNG explanation. The `sleepGallery` screenshot case captures `sleep-settings`, `sleep-gallery` and `sleep-greeting` through the production UI, including dark mode and large interface text.

`desktop.sleepRandomStatusSelection` selects Random status in the Custom editor. `model.appearance-settings` checks the eligible statuses, the saved backdrop and separate power-off settings. `lifecycle.sleepRandomStatusUntilWake` and `platform.kobo-power-screen` check the status across sleep, battery updates, power-off and wake in the reader and on Nickel Home, including private books.

`model.appearance-settings` also checks the Custom screen: defaults, round trips through normalization, invalid fields one by one, the sleeping and power-off looks, the backdrops each look prepares, the legacy pair an older release reads, and starting from a preset. It checks that positions save only valid, moved places and that a book's position wins over the global one. `lifecycle.sleepCustomPowerOffUsesItsOwnLook` draws a Custom screen with a wallpaper from a temporary folder and a seal moved to the top left, checks the separate power-off look before and after sleep, and checks a book's own position. `lifecycle.sleepDesignsRepaintOnlyTheirStatus` repeats the repaint check for every other place of each status that moves. The `sleepGallery` screenshot case also captures `sleep-custom`, `sleep-wallpaper-help`, `sleep-custom-power-off` and `sleep-arrange`. `lifecycle.sleepKobaltFolderStaysOutOfNickelLibrary` checks how Kobalt adds `.adds/kobalt` to Nickel's scan exclusion: alone, beside a reader's own pattern, unchanged when a dot-folder rule already covers it or the pattern is invalid, and removed again on uninstall. It does not run Nickel's library scan. These checks do not cover JPEG orientation on Kobo, where Qt 5.2 cannot read it, or wallpaper decoding time on device storage.

`lifecycle.sleepWidgetsKeepTimeAcrossSessionTimeout` keeps the Today total across a reading-session timeout. `lifecycle.sleepWidgetsUseLocalDay` checks continuous reading across midnight, short sleep, several days asleep, expired and retained sessions, and a new day with no reading. `lifecycle.sleepWidgetsUseSavedDay` checks totals from another book, checkpoint exclusion and reopening. `model.reading-history` checks local-day persistence, reopen totals, checkpoint exclusion and failure retries, and the 23-hour and 25-hour daylight-saving days. Its explicit Central European timezone rules do not require an installed timezone database. `lifecycle.sleepPowerOffWithoutCoverKeepsDesign` checks that coverless designs show the selected power-off screen after sleeping, using the reading-page fallback.

`lifecycle.sleepMetadataStaysInsideItsLayout` checks that long titles, chapter names and author names do not overwrite reserved screen areas. It covers unbroken words, mixed scripts, combining characters, emoji, line breaks, markup and oversized metadata in both themes and orientations. `lifecycle.sleepLetterPreservesLiteralPlaceholders` checks that percent placeholders in a book title remain literal. The status repaint check also uses long metadata and greetings.

`lifecycle.sleepHandoffKeepsPortraitDirection` checks sleep capture in all four reading orientations, including private books. It checks both values of Follow reading orientation. The default keeps all four directions; disabling it uses portrait layouts and retains inverted portrait. Both retain the reading size and page on wake. A later power-off snapshot keeps the captured direction after native handoff. `platform.kobo-power-screen` compares asymmetric image pixels through the production sleep presenter before and after native orientation changes. It checks both landscape directions against the physical bezel position on Clara Colour and on panels with the standard rotation. `lifecycle.sleepBackdropsUsePortrait` checks portrait conversion for saved cover, page, PNG and plain backdrops, including repeated conversion and preservation of the source image.

`lifecycle.sleepNativePreviewFollowsSettings` checks the native preview with covers hidden, inset covers, full-screen covers and full-screen information panels. Inactive options must not change the preview.

`platform.kobo-power-screen` checks that the native power-screen owner renders the selected design from a prepared backdrop. It checks that duplicate battery notifications and percentage changes while unplugged cause no paint, and that charging changes still update the Home sleep screen. It also checks the screen outside the reader: Kobo's screen and a book Kobalt never opened stay Nickel's, a Kobalt book draws its design with its own position and Nickel's progress on blank paper when no cover is cached, and Reading page draws over a capture of the visible Nickel window. It does not read a real Nickel cover cache; the cover path follows the folder naming of Nickel's cache and needs validation on a device. A sleeping reader retains ownership of its book even after its window hides for the native sleep handoff.

`lifecycle.sleepPrivateBookOverridesEveryDesign` checks a private book against each sleep design from a landscape reader, including Stock, Reading page and PNG over text. It checks each retained design and its anonymous progress, compares sleep and power-off pixels, rejects identifying metadata and cover references, checks the saved book choice and restores reading on wake. `desktop.settingsSleepPrivacy` saves through System, switches books, reopens and disables the choice without writing a global preference. `platform.kobo-power-screen` also checks that a private last-read book ignores saved images and global designs, survives a fresh screen owner and does not transfer its choice to another last-read book. These are controlled host checks, not physical firmware or e-ink evidence.

Private previews compare every design against a sanitized backdrop with anonymous progress and deliberately identifying source metadata and book pixels. `lifecycle.sleepPrivateBookCloseSavesAnonymousDesign` checks close-time handoff and reopening. The overlay check also exercises partial alpha above a private opaque page. The native power-screen check restores a private snapshot's anonymous progress through a fresh screen owner.

`lifecycle.sleepRefreshUsesDisplayedContent` checks the outgoing text page, an illustration with the next text page queued, colored highlights, and the full-screen image viewer. `lifecycle.sleepClassifiesReaderOverlay` checks plain text in both themes, a color thumbnail and a grayscale image. A native dialog over the text page still requests cleanup. `platform.kobo-power-screen` checks that text, gray and colored screens in Nickel each request one full refresh and that duplicate presentations request none. Physical ghosting still needs device validation.

The sleep-screen settings check toggles Follow reading orientation and verifies both saved Boolean values and confirmation messages. Gallery previews use the reading shape when enabled and portrait when disabled. The sleep gallery captures include both rotation-button states, their confirmation popups and landscape private designs. These headless checks do not establish physical-device orientation behavior.

The sleep rotation button uses the shared `CheckCellButton`: an icon slightly left of center and a separate lower-right checkbox. `component.ui` checks its visible checked state, toggle delivery, disabled behavior and stable icon position across screen densities.

`platform.kobo-power-screen` holds the snapshot worker while a close and a new opening queue a save and its deletion. It checks that both calls return before the worker resumes and that the old image is removed. `platform.native-lifecycle` holds the same worker across standby, USB and power-off and checks that storage stays with Kobalt until the work finishes. It also starts the adapter during a stock USB export, distinguishes a declined workflow from a completed remount and checks that unplugging during stock power-off keeps storage closed.
