# Sleep, USB and power

Saving a highlight immediately before sleep finishes the accepted save before hardware suspend. The engine pauses after the save's text queries finish, and a write that completes after the initial sleep checkpoint requests another checkpoint before suspend. Sleep alone does not save an unconfirmed selection.

Kobalt checks for Nickel's sleep view after the sleep transition and when a native power view opens. This provides a fallback when another add-on replaces Kobalt's sleep-view hook. The fallback waits for Nickel to report a visible sleep view and does not cover a PIN prompt. `sleep-view-handoff` records the hook or fallback path, while `sleep-view-unavailable` records a check that could not hand off. These events and `sleep-start` describe the application transition. They do not prove that the hardware entered suspend.

For Nickel Screensaver 1.3.1, Kobalt checks the power-off callback chain before opening its reader. If Screensaver has replaced Kobalt's hook, Kobalt reconnects its save gate through Screensaver's call-through pointer. Both load orders retain Screensaver's image preparation and wait for Kobalt's required saves before Nickel powers off. This also applies to battery-low software shutdown. An unrecognized callback chain leaves Kobalt unavailable for that startup attempt and records `screensaver-power-hook` with `ready=false`. Kobalt does not rename libraries or reinstall another mod.

Use Kobo's built-in sleep-screen option when Nickel Screensaver should supply the image. The Kobalt options display their own image above Nickel's sleep view. Nickel Screensaver 1.3.1 recognizes only Nickel's built-in reader for its reading-page overlay. Kobalt can use the same PNG files directly in its own overlay mode. Nickel Screensaver still handles its own wallpaper settings when Nickel controls the sleep screen.

Before sleep, Kobalt saves its position and pauses its work. The page stays on screen until Nickel's sleep screen is ready. Kobalt then shows the sleep screen with one full refresh, which also clears the page, so the screen flashes once, as in Nickel's own reader. While Kobo's awake PIN screen is visible, Kobalt lets Kobo receive orientation sensor readings so the PIN screen can rotate. Kobalt keeps the saved reading orientation and stays hidden. Returning to sleep blocks those readings again. After wake, Kobalt waits for Nickel's sleep or PIN view to close and for USB storage to finish remounting. It then checks authorization and restores page-turn input before it shows the book again. The frontlight can finish fading in while the page is already visible. If wake or USB cancellation arrives while the previous operation is still releasing resources, Kobalt completes that release before checking authorization again.

Settings > System > Hide this book while asleep saves a privacy choice for the open book. It keeps the selected Kobalt design, progress and status while hiding the cover and identifying text. Reading page uses a blank background, and PNG over text keeps its artwork over that blank background. Kobo’s screen uses a safe Kobalt status card. No cover, title, author, chapter or reading-page text is used. Cover-based designs retain their status elements over black. Cover shows a question mark in place of its hidden cover. Widgets omits the book tile. Framed leaves the artwork area empty. Night and Letter use anonymous progress text. Other books retain their own choices. The choice survives reopening and Mark as unread. When Kobo's last-read book has this choice, Kobalt also covers the native sleep and power-off screen after the reader closes. If the last book or its choice cannot be read, Kobalt uses the neutral screen until it can verify the choice. This requires Kobalt to remain installed and enabled; older builds and another reader do not apply the choice.

On Kobo and Tolino, Settings > System > Sleep screen while reading opens the Lock screen gallery. It shows four previews per page with the current book and reading progress. Tap a preview to save it and close the gallery. Use Kobo’s screen is first, Custom is second, Reading page is third, and Bookmark is fourth. The setting also applies outside the reader, such as on Home and in My Books, when Kobalt opened Nickel's last-read book. Kobalt then draws the screen at sleep or power-off from current data: the book's saved position for its status, Nickel's progress, title, author and full-size cover, and the wallpaper folder. Nickel's progress matches My Books, also after reading the book in Nickel's own reader. While Nickel's own reader shows a book, Nickel keeps its own sleep screen. Reading page and PNG over text dim Nickel's current screen, such as Home, and draw the status over it. PNG over text adds a PNG from the same folders as in the reader. If Kobalt cannot capture that screen, it uses the cover. Without a cover or wallpaper, the status stays on blank paper. Use Kobo’s screen, a last-read book that Kobalt never opened, or an unreadable Kobalt book state leaves Nickel's screen. Outside the reader, the text and remaining time that need an open book are left out. Kobalt keeps the reader backdrop in memory for the current sleep. Closing a book or connecting USB does not save a backdrop for later use.

Bookmark is the default. Bookmark, Card and Cover use Kobo's full-screen cached cover if available, then the cover embedded in the book. The image fits without cropping and empty space is black. If no cover is usable, Kobalt uses the reading page. Reading page dims the current page. An unavailable or changing page uses Kobo's sleep screen. Menus and dialogs are omitted and clock slots show a lock icon. Use Kobo's screen uses Nickel's normal image.

Seal, Stamp, Pill and Caption add status information to the full-screen cover. Widgets places a smaller cover above reading progress, today's reading time and the remaining time. Today counts active reading since local midnight, across books and sleep, without resetting the reading-session timer. The next sleep capture uses the current date even when the book has stayed open for several days. A screen already displayed while asleep is not repainted at midnight. Framed shows the cover on paper with the status, progress and remaining time below it, so no text covers the art. Night, Ring, Lines and Letter use typography instead of the cover. Letter uses the chosen reading font, with Libron as its fallback. Kobalt sleep screens follow the reading orientation by default, including both landscape directions and inverted portrait. Turn off Follow reading orientation with the rotation button beside Close in the sleep-screen gallery to keep portrait sleep screens. Inverted portrait reading still keeps its direction; landscape reading uses upright portrait. This can give portrait covers more space. Wake restores the reading orientation. With Follow reading orientation off, page and PNG backdrops captured in landscape fit inside the portrait screen without cropping or changing the reading page. Kobo controls the orientation of its Stock screen. Long book titles, chapter titles and author names stay within their text areas. Text that does not fit ends with an ellipsis. Letter reserves room for its charging message, wake instruction and signature. Line breaks in metadata become spaces. These display limits do not change the book metadata. Battery changes redraw only each design's status area.

Custom combines one background with one status. The backgrounds are Book cover, Reading page, PNG over page, Wallpaper and Blank. The statuses are None, Bookmark, Card, Seal, Stamp, Pill and Caption. Tap Custom in the gallery to open its editor. The editor shows the screen large, with a Background row and a Status row that step through the choices. Each row shows its place in the list, such as 2 of 7. Done saves Custom and returns to the gallery with Custom chosen. The first time the editor opens, it starts from the chosen design when that design is a background with one status. Same screen for sleep and power off is on by default. Turn it off to edit a separate power-off screen with the Sleeping and Powered off buttons. Charging uses the sleeping screen. A Custom screen with a hidden book keeps its status over the neutral background and leaves out its wallpaper and PNG.

Put PNG and JPEG wallpapers in `.adds/kobalt/wallpapers` on the Kobo drive. The question button in the editor's header explains this. Kobalt records the previous value when it adds its folder. Uninstall restores that value if the setting still matches what Kobalt wrote. Kobalt adds `.adds/kobalt` to Nickel's `ExcludeSyncFolders` setting when it starts, so these images and the PNGs for PNG over text stay out of My Books. It keeps any exclusion that is already set, and does nothing when that already covers `.adds/kobalt`. Removing Kobalt takes its part out again. The Background row has one stop for each file and a Random wallpaper stop before them. Random picks a file at random again after each wake, which can be the same one. Kobalt decodes wallpapers off the reading thread when a book opens, and again after wake only for Random. They are scaled to cover the screen within the image limit. The Custom editor decodes a wallpaper at the size of its preview. A wallpaper fills the screen and is cropped at its longer side. Without a usable wallpaper, the reading page stands in, as for a book without a cover.

A status can move. Seal, Stamp and Card go in any corner. Bookmark hangs on the left or the right. Pill and Caption sit at the top or the bottom. In the Custom editor, tap a dashed area on the preview to move the status there. Hold Bookmark, Card, Seal, Stamp, Pill, Caption, Reading page or PNG over text in the gallery to open its position page, which works the same way. Reading page and PNG over text move their bookmark or card. A position belongs to the status, so the Seal design and a Custom screen with the seal share it. Only for this book on the position page keeps a separate position for the open book. A book's own position survives Mark as unread, like its privacy choice. Battery changes still redraw only the moved status.

Long-press Night in the gallery to change its sleeping greeting. The greeting accepts up to 40 characters. Save an empty field to restore Goodnight. Charging and power-off keep their state labels.

The bookmark overlay uses a light background with dark text and outline in light mode. Dark mode keeps a dark background with white text and outline. Power-off keeps the dark appearance.

PNG over text dims the reading page and draws a transparent PNG over it. Put your PNGs directly in `.adds/kobalt/screensaver` or `.adds/screensaver` on the Kobo drive. Kobalt chooses from both folders and can use either one on its own. It does not require Nickel Screensaver or use its wallpaper subfolders. If neither folder has a usable PNG, tapping its preview explains where to add one. An existing PNG selection falls back to the dimmed reading page until an image is available.

Settings > System has a Power management section with Smart Wi-Fi power saving on hosts that can turn Wi-Fi off for it. Kobo currently hides the section (`wifiPowerSaverReleased` in `platforms/kobo/common/reader_host_services.cpp`). Settings cleanup removes any saved choice, so the saver stays off. When enabled, the saver turns Wi-Fi off when a book opens and when the device sleeps; see [Power mechanisms](../power-mechanisms.md) for the rules at sleep. When a book opens and Wi-Fi is on, Kobalt turns Wi-Fi off through Nickel before the book takes input. The book must be one that Kobalt would sync with KOSync, and automatic KOSync must be off or not set up. Wi-Fi stays on for store books and books from services that sync through Nickel's own sync, because Nickel uploads their position. It also stays on with automatic KOSync, while Bluetooth is on or its state is unknown, and while Nickel syncs. Nickel turns Wi-Fi off by itself after about two minutes without network traffic. Firmware 4.x also waits until 15 minutes after its last Bluetooth activity signal. Nickel sends one when it starts and when its own reader opens a book, whether Bluetooth is on or not, so Wi-Fi can stay on for about 15 minutes. Opening a book in Kobalt does not send one. Desktop previews do not show the setting.

The gallery replaces the separate Sleep indicator setting. Reading page and PNG over text retain their previously saved Bookmark, Card or None indicator. Bookmark and Card show the status, percentage read and estimated time left when available. A finished book shows 100%. Both styles show battery level only while charging or charged, and update when Nickel reports a change. None shows only the page and any selected PNG. With a PNG, Bookmark and Card appear above the artwork. During foreground shutdown the selected design shows Powered off. Restart uses Kobo's restart screen.

Nickel's standard confirmations, progress dialogs and native dialog containers appear above the open Kobalt page, including Wi-Fi permission, connection and USB prompts. They keep Nickel’s widget parent and styling, with a temporary window above Kobalt. One copy of the covered reader area supplies the background until the dialog closes. Their native buttons and callbacks remain in charge. Reader shortcuts are paused until the dialogs close. Closing a dialog, sleeping or closing the reader restores the native window flags. The browser keeps its separate handoff. Cancel on the USB confirmation keeps the book open.

A confirmed USB connection waits for local reading data and native reading time to save before Nickel starts its USB workflow. This applies to a connection confirmed in Nickel's Connect dialog and to one Nickel starts without asking. The dialog reaches its Connect and Cancel actions through their function addresses, which a NickelHook call hook does not change, so Kobalt also points those address references at its USB hooks when it starts and logs the result as `usb-dialog-hooks`. Native progress keeps newer Nickel progress and allows two seconds for position conversion. Required storage saves retry on failure; the conversion deadline does not release unsaved data. Kobalt then closes the book and releases every file on user storage before Nickel exports the storage. If access to the book is revoked during the save, Kobalt still completes this cleanup and USB handoff. Reopen the book from the library afterwards.

Power-off, low-battery power-off and reboot wait for required local reading data and native reading time to save. Failed saves retry. There is no forced shutdown deadline that bypasses those saves or the engine drain. Native-position conversion still has a two-second deadline; a late conversion reply cannot write progress, but the local reading checkpoint is retained. The shared profile closes before Nickel continues shutdown. A failed or stuck save can delay shutdown indefinitely. This does not protect against physical power loss before a save completes. When the application exits, Kobalt stops its engine worker before releasing any remaining cached engine documents.

The Use Kobo screen preview follows Kobo’s current cover visibility, full-screen cover and information-panel settings. It represents the native layout with the open book’s cover and progress. Kobo draws the actual sleep and power-off screens.
