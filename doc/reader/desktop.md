# macOS testing app

The Mac app uses the same reader controls and renderer as the mobile app. The title bar is blank and keeps the standard window controls. The app opens in the [library](library.md#library). Open an unprotected EPUB from there, File → Open EPUB, Command-O, Finder's Open With, or by dropping one EPUB onto the window. Each opened book joins the library. File → Add Library Folder scans a folder. Removing a book from the library never deletes the file. Opening another book saves and closes the current book. The reader's Exit Kobalt button returns to the library.

The app starts with the six-inch e-reader preview at 300 DPI. The toolbar shows the Kobalt icon on the left, the screen and rendering-resolution pickers in the center and the application version on the right. The picker selects Fill window, 6-inch e-reader, 7-inch e-reader with buttons or 5.8-inch smartphone. The phone is a 720 × 1600 screen at 300 PPI with a camera in a 60-pixel band at the top and rounded corners, drawn over the screen. In landscape the camera side is letterboxed on both sides, as Android does, so the reader is 1480 pixels wide. Fill window changes the reading viewport when you resize the window and keeps controls the same size on standard and Retina displays. Moving the window between monitors or changing the monitor DPI redraws the reader. Text reflows after the resize settles. The 6-inch preset uses a 1072 × 1448 screen and the 7-inch preset uses a 1264 × 1680 screen, both at 300 PPI. These match Clara Colour and Libra Colour screen specifications. Rotate in the toolbar or View > Rotate Device (Command-R) switches any device preview, including the phone, between portrait and landscape. The frame and page buttons rotate with the device, and the book reflows without reopening or losing its reading position. Rotation stays selected when switching between device presets and is unavailable in Fill window. Each device preview has a black rounded body and a black screen border, without logos. The 7-inch preview has a wider side grip with working Previous page and Next page buttons without icons. All modes use the same 300 PPI layout for reading settings and controls. The second picker offers 212 DPI, 300 DPI and Native, with 300 DPI selected initially. The fixed resolutions produce a device image and use smooth filtering when fitting it to the window. Native draws controls at the Mac display resolution, including Retina pixels. Switching rendering resolution preserves the frame, book layout, page count and reading position. Book pages remain images at the layout resolution and are smoothly scaled when Native needs more pixels. Switching screens reflows the current book without reopening it. Device previews always show a simulated status bar with a fixed 09:00 clock and full battery. Fill window hides the simulated status bar and leaves Battery slots empty; the time remains available in the header and footer. Lookup is available in Fill window and hidden in device previews. In device previews, tap within the middle third of both the screen width and height to open or close the reading menu. While a Text or Layout panel is open, a tap anywhere on the visible page closes it. These presets simulate layout and text density, not the colour filter or e-ink refresh. Left and Right, or Page Up and Page Down, turn pages while reading. Reader controls remain available through the page's touch-style controls. Mouse and trackpad clicks use the same controls: click the center of the page to show the reading menu, or the left and right sides to turn pages. Closing the window saves the reading state and waits for the engine to finish. The six-inch and seven-inch previews also have Sleep and Power off. Sleep calls the same reader steps as the Kobo power button: the reader prepares for sleep, hands the screen to the sleep view and is reported as suspended. An Asleep screen then covers the preview and ignores taps. Wake returns to the page through the same wake steps. Power off closes the book through the same save the Kobo host requests before power-off, shows a Powered off screen and returns to the Library on Power on. The phone preview and Fill window have neither, because Android and the Mac have no device sleep. These controls exercise the reader lifecycle only. Nickel’s own sleep screen, USB and battery events are not simulated.

View > Device and View > Rendering Resolution offer the same choices as the toolbar. Their checkmarks follow the toolbar selections. View > Show Toolbar hides or restores the preview toolbar; Option-Command-T does the same. The toolbar context menu uses the same Show Toolbar action, so a hidden toolbar can always be restored from View. Hiding or showing it fits the reading area again. Fill window reflows to the available space; device frames keep their fixed layout and page count.

Settings, bookmarks, reading positions and cached layouts stay under `~/Library/Application Support/Kobalt/Kobalt/config/`. A build from a Git worktree uses its own profile; see [Building](../building.md#mac). Logs go to the adjacent `diagnostics/` folder. Add personal reading fonts to the adjacent `fonts/` folder and reopen the book. Bundled fonts come from the app, so the reader does not depend on macOS font fallback.

The gear in the toolbar opens Settings. Its tabs show an icon above a label, as the bottom tabs do. Defaults appears immediately below Controls, and new-book inheritance and Restore appearance defaults belong there. Fonts follows Defaults and selects generic-family fallbacks. Books uses a stack-of-books icon and contains book-content options. The tab rail is as wide as its widest visible label, so it narrows where Lookup is not shown. Its rows have two extra pixels above and below at 300 PPI and fit the available height. Unsupported hardware options remain visible and explain why they are disabled. Each settings option and list action draws its own bottom divider, including the last row in a tab and the choices in the screen-refresh popup. The refresh choices use equal-height rows with edge-to-edge separators and a top rule; adjacent rows share one separator. Remaining controls keep their normal height, with spare space below them. These preferences persist on the Mac and do not change the screenshot fixture.

This build is for renderer testing. It has no Nickel library integration, brightness controls or e-ink refresh. Downloaded dictionaries work on desktop and Android. Vertical text uses the same layout engine as the device builds. See [Building on macOS](../building.md#mac).
