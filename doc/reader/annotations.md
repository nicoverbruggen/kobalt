# Bookmarks and annotations

## Bookmarks

Tap the top-right area of the page, covering the rightmost 33% of its width and 120 pixels in height at 300 ppi, to bookmark the page or to remove its bookmark. A link in that corner still opens. A bookmarked page shows a ribbon at the top: with a header it hangs just left of the top-right slot and runs a little past the strip, and without a header it is shorter and stays in the top margin. A page keeps at most one ordinary bookmark. Pinned bookmarks retain separate destinations after reflow. With no saved bookmarks, the first tap is available as soon as the reading page is ready after opening or reflow. When a layout change puts several ordinary bookmarks on one page, they become one at the page start with the oldest date. The bookmark icon next to the menu button opens Bookmarks, sorted by page: each row shows the chapter, the page, the page's first words and the date. Opening Bookmarks while a bookmark is saving keeps the list open and shows the new row when saving finishes. Saving a bookmark does not change the selected Annotations tab. An open Bookmarks list updates its page numbers when a layout change finishes. A row goes to its page and saves the passage you left, as an internal link does. Open the reading menu to return to that passage. Bookmark and link jumps share the same return history, so repeated returns retrace multiple jumps. Completed jumps refresh the reading text, header, footer and bookmark ribbon together without a page-turn animation. Page turns and layout changes keep the saved passages. A failed jump or a jump to the current position adds no return entry. The bookmark button at the top right of the Bookmarks tab offers Bookmark current page or Remove bookmarked page. Each row's … menu offers removal with confirmation. Removing a pinned bookmark also removes its shortcut. Removing it from the page corner or the current-page action asks for the same confirmation. Cancel keeps the bookmark and shortcut. Opening a bottom navigation tab closes Bookmarks and opens that tab. Annotations comes before Bookmarks in the shared menu. The menu opens Annotations when the book has saved highlights, and Bookmarks otherwise, including when both lists are empty. Both headings use the same Kobalt typeface as Chapters. The Text tab shows Aa in the selected reading font, including pending font changes. Opening Bookmarks from Settings, Text or Layout applies the pending changes first. If saving settings fails, the current panel stays open and shows the error.

The Bookmarks toolbar shows a bookmark with a plus to add the current page, or a crossed-out bookmark to remove it. List rows, their trailing action buttons and popup-menu actions use gray press feedback. Selected rows and tabs keep their active styling. Open a bookmark row’s … menu and choose Pin bookmark to give it a name and icon. The icon picker offers four pages of twelve choices, in three rows of four. A screen shorter than 3.4 inches, such as a phone in landscape, shows one row of six per page, on eight pages. When the on-screen keyboard leaves too little room, the editor hides its title and keeps the name field and its buttons. Previous and Next change the icon page without changing the current selection. Editing a pin opens the page containing its icon. Tap the name field to show the keyboard. Done returns to the icon choices; Save stores the name and icon. Save adds it to a floating capsule centered vertically near the right edge between the toolbars. Shortcuts stack vertically, with one outer border and short dividers between icons. The capsule has rounded ends and a gap from the screen edge. It grows to fit the shortcuts. When the shortcuts cannot stack at a usable size, as on a phone in landscape, they use separate capsules with a gap between them. The columns have nearly equal numbers of shortcuts and are centered between the toolbars. The gap shows the reading page. The bar appears when the reading menu is open and no panel is open. Each book permits up to eight pins. Pinned rows show a pin icon beside the name. The shortcut tray uses each bookmark’s assigned icon and orders shortcuts by their position in the book. Tap a shortcut to jump to its saved passage. Moving between pinned shortcuts keeps the return destination at the reading location before the first shortcut. Return takes you back there; the next shortcut starts a new return point. Ordinary bookmark and link jumps keep their normal return history. For pinned bookmarks, the first action is Modify pinned bookmark. Use it to rename the bookmark or change its icon. Choose Unpin bookmark in the same menu to remove its shortcut and keep the bookmark. Choose Remove this bookmark to delete it after confirmation.

Bookmarks are Kobalt's own and separate from Nickel's. Each book has a folder in `.adds/kobalt/annotations/`: `kobo-<id>` for existing UUID book IDs, `kobo-id-<hash>` for other server IDs, and `file-<fingerprint>` for sideloaded books. The server-ID hash preserves case and keeps arbitrary ID characters out of folder names. A moved or renamed sideloaded file keeps its bookmarks through the content fingerprint. Existing UUID folders stay unchanged. `book.json` records the book's identity and title. When a sideloaded file changes, its bookmarks come from the most recently saved folder for that path and move to the new folder on the next save. If saved bookmarks cannot be read, Kobalt keeps the file intact and disables bookmark edits until you fix the file and reopen the book. Opening Bookmarks or tapping the bookmark corner shows an error. If a bookmark save fails, Kobalt shows an error and keeps the previous list and ribbon state. This also applies to automatic merges after a layout change and saves that exceed the 1 MiB storage limit.

Changed-file bookmark lookup keeps a disposable index in `annotations/.index/paths.json`, limited to 4 MiB and 10,000 book folders. The first lookup in an existing library reads the book metadata to build it. Later lookups check the folder inventory and metadata file stamps, then read only matching books. Missing, invalid or stale indexes are rebuilt. Deleting the index does not delete bookmarks.

## Annotations

Bookmarks & annotations opens the shared list. Book order is the default and orders annotations by their exact source position, including passages on the same page. The Sort button in the list header opens the shared choice dialog. Newest first and Oldest first order both tabs by creation time. The choice is saved across books and restarts. Lists open on their first page in the selected order. Both lists use smaller chapter headings, a gap before the excerpt and up to two excerpt lines with extra line spacing. Annotation excerpts use the saved color and shading, solid underline or dotted underline. Bookmark excerpts stay plain. Both tabs show the local creation date and time.

Reading resolves only the saved highlights visible on the current page. Opening the annotations list resolves the saved passages' page numbers and book order when needed. The list shows Finding pages… while that work runs, with the tabs and close button still available. Page turns keep resolved locations for the current layout. Reflow invalidates those locations; recoloring or restyling a saved passage preserves them.

Hold a word for half a second to select that word. Hold detection uses input timestamps when rendering delays delivery. Cancelling a contact cancels its pending hold, including in the library and font picker. In normal reading, releasing it opens dictionary lookup. The selection has an outline and adjustment handles. Moving during the initial hold keeps the original word. After release, drag either handle to select a phrase. Releasing a handle looks up the complete phrase in the selected dictionary, with line breaks and repeated spaces treated as one space. Lookup handles stay on the current page and do not enable highlight mode or save an annotation. Tap inside the selection for Dictionary and applicable link actions. Normal selection menus offer dictionary lookup, applicable link actions and Clear selection, without annotation tools. Closing the dictionary with X or a tap outside the selection clears the entire lookup selection and its handles when highlight mode is off. The outside tap does not turn a page or open the menu. Closing the dictionary requests a full screen refresh. Enable highlight mode from the reading menu before selecting text to annotate. Highlight mode also allows held selection and handle dragging across pages. Saving or clearing a selection keeps that mode active until you turn it off. Ordinary taps keep their page and menu actions. Ordinary swipes keep turning pages. A short tap on a saved highlight does not edit it.

Open the reading menu and tap Annotate beside Bookmarks to toggle highlight mode. Enabling highlight mode closes the reading menu. Reopening the menu still uses the configured Stats or Navigate default view while highlight mode is enabled. The button stays selected whenever the menu is open while the mode is active. Tap it again to leave highlight mode. Both changes close the reading menu and briefly show a centered indicator in the same style as brightness and warmth feedback. The indicator shows On or Off with the annotation icon; Off adds a slash through the icon. It disappears after 850 milliseconds and does not intercept page input. There is no persistent instruction panel over the page. In highlight mode, with only the reading toolbar open, long press exposed text to close the menu and start selecting in the same gesture. Keep dragging to extend the selection. A brief central two-finger tap on Kobo, or a right-click on Mac, also enters the mode while reading.

In highlight mode, hold a word to start selecting, then drag to extend. Hold a saved highlight to change it. Release keeps the selection menu closed. Tap inside the outlined selection to choose its appearance and save. Inter-word spaces select the preceding word. Margins and paragraph gaps do not start selections. Handles drag immediately, in either direction and across each other. They remain usable while the mark choices are open; starting a grip drag closes the choices and keeps the selection. Expanding requires dragging past the far edge of the added word. At a line boundary, dragging into the adjacent margin includes the first or last word. Off-page endpoints have no handle. Clear selection discards the draft. Tapping outside the menu closes it and keeps the draft. Swipes and hardware page buttons still turn pages. A highlight can cross pages within a section. Automatic handle dragging stops at EPUB spine sections, semantic sections and table-of-contents chapter boundaries. At those boundaries it selects the first or last word on the current page and ends the drag. Ordinary paragraph endings do not block continuation. In highlight mode, drag either handle beyond the first or last word to turn to the previous or next page and continue selecting. Each cross-page extension ends the drag at the last word of the previous page or the first word of the next page. Holding or moving the same press cannot turn another page or move that boundary. Release and grab a handle again to continue adjusting the selection. An extension cannot cross another saved highlight.

The start and end tokens are included, in either order. Ending on a sentence's final word includes its terminal punctuation when the whole final sentence is selected. A fragment keeps the exact word ending. Kobalt omits automatic punctuation when an ellipsis, abbreviation, decimal or limited context makes the sentence boundary uncertain. A complete first sentence can include its attached opening quote or bracket when the matching closing mark is included. A closing quote or bracket is included only when its opening mark is selected in that sentence. Automatic punctuation keeps pairs balanced. Moving a boundary recalculates punctuation from the chosen words. Saved highlights retain those chosen boundaries for later adjustment. To choose an exact punctuation ending, tap the punctuation directly. Older saved highlights keep their exact boundaries until you choose a new boundary.

The menu uses paper-colored headings and a fine grid, with a thin divider below each heading. Color swatches and their labels are centered vertically in their row. Color choices appear first when available, followed by Shaded, Solid and Dotted in the Style section. Each style stays on paper with a small checkmark for the selected choice. The mark choices remain available on grayscale displays. Actions stay below the choices: Mark text and Clear selection for a draft, or Apply changes, Adjust and Delete for a saved highlight. Saved-highlight actions share one row. There is no Dismiss button; tap outside the menu or press Escape to close it. Action cells place their icons above full labels at the same text size as the style samples. The selected style is checked. Color displays offer Yellow, Green, Blue, Pink and Gray above the style samples, with a divider below the palette. Changing a choice updates the samples without saving. Mark text saves both choices and dismisses the menu. New highlights use the last saved style and color, initially Shaded and Yellow. Underlines and dotted underlines use the chosen color. Grayscale devices omit the color picker, draw shading in gray and use black or white underlines. They preserve stored colors. Outlines mark only the draft being adjusted. A long press on saved text opens that highlight’s actions only in highlight mode. Outside highlight mode, it looks up the selected word. In highlight mode, selection handles stop before another saved highlight, including when dragged beyond it. Adjust changes the saved passage without allowing it to overlap a different highlight. Tapping outside the menu, including on the selected text, dismisses it without turning a page or opening the reading menu. In annotation mode, the draft and its choices remain available. Outside annotation mode, dismissal clears the word selection. A failed save keeps the draft for another attempt. Annotation mode stays active after saving.

Saved highlights are local to Kobalt. Open Bookmarks and choose Annotations to see each saved passage once, with its excerpt and page or page range. Tap a row to go to its start. The row's remove button asks before deleting. Bookmarks and Annotations use the interface font for labels and the selected reading font for excerpts, at the same size as Search results. In annotation mode, hold a saved passage for its appearance pickers and Apply changes, Adjust and Delete actions. Apply changes saves the chosen color and style together and dismisses the menu. Closing the menu abandons unsaved appearance changes. A failed change keeps the previous saved appearance. Adjust explicitly enters annotation mode and loads the saved range as an outlined draft with handles. Apply changes saves the adjusted range with the same ID. Close or Clear selection discards the adjustment and keeps the saved original. New highlights and range edits cannot overlap another saved highlight. A rejected save keeps the selection and saved passages unchanged. Legacy overlapping highlights remain readable. Switching away from a failed complete draft offers save and discard actions; tapping outside keeps the draft. Highlights have no note editor.

Ordinary reading taps keep their page and menu actions. A tap on ordinary book text does not open word actions. Link taps follow the Tappable links setting. Long press still opens dictionary or link options deliberately.

The action at the far right of the header, after Sort, follows the active tab. Bookmarks shows a bookmark icon and offers Bookmark current page or Remove bookmarked page. Annotations shows an export-arrow icon. Both buttons stay visible when their list is empty. The menu opens a centered card with the same patterned backdrop as Library. It covers the full reader, including the status bar, tabs and bottom controls. Tapping outside the card dismisses it without activating the controls underneath. On Annotations, the card has Export as Markdown… and Export as HTML… actions. A shared description above the two actions explains ZIP compression and extraction. The card uses the standard action menu with single-line icon rows. A pressed row uses the shared gray background and keeps its normal text and icon colors until release. Export is disabled when the annotation list is empty or unavailable. Choose one format from this card. Each format action has a ZIP-file icon. It exports every saved highlight, including its chapter, creation timestamp and any saved note, in a ZIP containing either UTF-8 `annotations.md` or `annotations.html`, according to the selected format. Each document includes the book title and author. Its suggested filename uses a shortened book title, a book identity hash and a `-markdown.zip` or `-html.zip` suffix. The two formats have separate destinations. Confirm Export ZIP before exporting. The confirmation identifies the book and selected format. On Kobo, it also shows the destination under `Kobalt/Annotations/` at the root of the drive. If an export exists, the dialog asks Replace annotation export? and requires Replace ZIP. Cancelling preserves the existing file. Kobalt checks again before writing if a file appeared while the first confirmation was open. On Mac and Android, confirming Export ZIP opens the system save picker, with its overwrite confirmation enabled. Choose the filename and location there. Cancelling the picker creates no export. A failed write shows an error. Local file exports use atomic replacement; Android document providers control how their files are written. Export does not change annotations or Nickel settings. The HTML opens in book order and includes a Sort by list for Book order, Newest first and Oldest first. Date sorts order all annotations together and show each annotation’s chapter. Search filters passages, notes and chapter labels. HTML uses compact `#1`, `#2` annotation links. The numbers stay fixed when the order changes. Exported passages use the saved highlight color and marker or underline style. Libron is embedded for the passages, so the HTML does not need a font download. Timestamps include the time; HTML uses the browser’s locale and timezone, and Markdown uses UTC. Exports do not include page numbers. The checked Show annotation styling option below search hides or restores marker fills and underlines. It keeps passages, notes and the embedded font visible, and applies to printing.
